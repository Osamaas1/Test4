GitHub & Git Fundamentals

Master version control and collaboration with Git and GitHub

What is Git and GitHub?

🔀 Git - Version Control System

Git is software that tracks changes to files. It keeps a complete history of every modification, allowing you to see who changed what and when. It's like "track changes" on steroids.

Real-world analogy: Git is like having a time machine for your code. You can go back to any previous version if something breaks.

🐙 GitHub - Cloud Hosting for Git

GitHub is a website that hosts Git repositories in the cloud. It provides collaboration features, access control, and a platform to showcase your code to the world.

Real-world analogy: If Git is your local notebook, GitHub is a shared whiteboard where teams collaborate and save everything online.

Why do you need both? Git works locally on your computer. GitHub stores your code online so you can access it anywhere, share it with others, and backup your work.

Key Concepts

📦 Repository (Repo)

A folder that contains your project files and the complete history of changes. Think of it as your project's home directory.

🌳 Branches

Independent lines of development. The main branch is usually called "main" or "master". You create branches to work on features without affecting the main code.

Example: You work on "add-login-feature" branch while your teammate works on "fix-bugs" branch. No conflicts!

💾 Commit

A snapshot of your code at a specific point in time, with a message describing what changed. Each commit is like a save point in a video game.

Example: "Fixed login button styling" or "Added user authentication"

🔄 Push & Pull

Push: Upload your local commits to GitHub (sending your changes to the cloud)

Pull: Download updates from GitHub to your computer (getting others' changes)

🔗 Pull Request (PR)

A proposal to merge code from one branch to another. Other developers can review your code, suggest changes, and approve before merging.

Why it matters: Prevents bad code from breaking the main project. Essential for team development.

Essential Git Commands

These are the commands you'll use 90% of the time. Master these first.

Setting Up Git

git config --global user.name "Your Name" git config --global user.email "your.email@example.com"

Starting a New Project

git init

Turns a folder into a Git repository

Getting an Existing Project

git clone https://github.com/username/project.git

Download a repository from GitHub

Saving Your Work

git add .

Stage all changes for commit

git commit -m "Your message here"

Save changes with a descriptive message

Uploading to GitHub

git push origin main

Send commits to GitHub

Getting Updates

git pull origin main

Download latest changes from GitHub

Creating a Branch

git checkout -b feature-name

Create and switch to a new branch

Checking Status

git status

See what files have changed

Typical GitHub Workflow

1

Clone the Repository

Download the project to your computer

git clone https://github.com/user/project.git
2

Create a Feature Branch

Work on your feature without affecting the main code

git checkout -b add-dark-mode
3

Make Changes & Commit

Edit files, save changes, and commit with meaningful messages

git add .
git commit -m "Add dark mode toggle"
4

Push to GitHub

Upload your branch to GitHub

git push origin add-dark-mode
5

Create a Pull Request

On GitHub, create a PR to merge your branch to main. Describe your changes clearly.

6

Code Review & Merge

Team reviews your code, suggests improvements, and merges when approved.

GitHub Features You Should Know

📝 Issues

Track bugs, feature requests, and tasks. Discuss problems before fixing them. Essential for project management.

🤝 Code Review

Comment on specific lines of code in pull requests. Ensure code quality before merging to main branch.

📊 Project Boards

Organize tasks like a Trello board. Drag issues and PRs through To-Do, In Progress, and Done columns.

🌐 GitHub Pages

Free hosting for static websites directly from your repository. Perfect for portfolios and project documentation.

🔗 Actions (CI/CD)

Automatically test, build, and deploy your code when you push. Advanced but powerful feature.

👥 Collaborators

Invite teammates to repositories. Control permissions: read, write, or admin access.

GitHub Tips for Students

✅ Use Meaningful Commit Messages

Bad: "fix stuff"
Good: "Fix login button alignment on mobile"

✅ Make Commits Frequently

Commit after completing a feature, not at the end of the day. Easier to track changes and revert if needed.

✅ Create a .gitignore

Tell Git which files to ignore (passwords, API keys, node_modules, etc.). Never push secrets!

✅ Always Pull Before Push

Run git pull before pushing. Prevents conflicts if teammates pushed updates.

✅ Build a Strong Portfolio

Employers check your GitHub. Create diverse projects, write good README files, keep repos organized.

✅ Contribute to Open Source

Find beginner-friendly projects, contribute fixes or features. Great resume builder and learning opportunity.
