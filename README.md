# Test4 Project

A static website project with multiple pages and styling.

## Project Structure

```
├── index.html        # Main landing page
├── about.html        # About page
├── github.html       # GitHub page
├── aws.html          # AWS page
├── resources.html    # Resources page
├── script.js         # JavaScript functionality
├── styles.css        # CSS styling
└── README.md         # This file
```

## Files Overview

- **HTML Files**: Static HTML pages for different sections of the website
- **script.js**: Contains JavaScript functionality for the website
- **styles.css**: Contains all CSS styling for the website

## Getting Started

Open `index.html` in a web browser to view the website.

## Features

- Multiple navigation pages
- Responsive styling with CSS
- Interactive functionality with JavaScript
